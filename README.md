## 🌐 React-Dashboard-Pizza
Exemplo de Dashboard em React 18 Radix UI com Mock Service Worker.

#### 🎨 Aqui está uma demonstração do Projeto
[https://dash-board-franquia.vercel.app/](https://dash-board-franquia.vercel.app)

#### 📋 O que voçê vai ver nesse Projeto
| Tecnologia | Descrição |
|-----------|-----------|
| **MSW**  | Biblioteca de JavaScript usada para simular (mockar) requisições de API. |
| **Radix UI**| Biblioteca de componentes para React focada em acessibilidade, comportamento e componentes sem estilo (headless) |

#### 🔄 Executar a aplicação
- Recuperar as dependencias do projeto node_modules . 
```bash
pnpm install
```
- Executar o Build do Projeto

```bash
pnpm dev
```
